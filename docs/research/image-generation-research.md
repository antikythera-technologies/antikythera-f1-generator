# Image Generation Research

> Last updated: 2026-03-09
> Status: In progress — style locked, likeness unsolved

## Goal

Generate satirical caricature portraits of all 42 F1 characters (22 drivers, 11 team principals, 9 pundits) in a consistent style for use as video scene images.

## Requirements

1. **Recognizable likeness** — each character must be identifiable as the real person
2. **Consistent style** — all 42 must look like they belong in the same show
3. **Caricature proportions** — oversized heads, exaggerated features, not photorealistic portraits
4. **Warm amber background** — burnt-orange to dark amber gradient
5. **Team-correct clothing** — correct team suit/colours for each character
6. **Portrait orientation** — 9:16 (768x1344) for video scenes

## Gold Standard (Lost)

The original 18 good images were generated by **Manus.ai** (exact pipeline unknown). Style characteristics:
- Hyper-detailed photorealistic skin (pores, wrinkles, stubble)
- Slightly oversized heads with exaggerated features
- Realistic eyes (NOT cartoon/googly)
- Warm amber gradient backgrounds
- Dramatic warm side lighting
- Best examples: Toto Wolff, Fernando Alonso

**This style cannot be reproduced** — Manus.ai pipeline is no longer available, and no cloud API tested can replicate it. A new consistent style must be chosen for all 42 characters.

## Models & Approaches Tested

### 1. Google Imagen 4 (via REST API)

**Endpoint:** `generativelanguage.googleapis.com/v1beta/models/imagen-4.0-generate-001:predict`
**Cost:** Free (Google API key)

**Result: FAILED — safety filters block real people**

- Tested ~9 prompt variations for George Russell
- Every variation either blocked entirely or produced generic unrecognizable faces
- "Caricature artwork" framing didn't bypass safety filters
- Direct name usage blocked; indirect descriptions lost all likeness
- **Verdict:** Imagen 4 cannot generate recognizable likenesses of real people. Dead end.

### 2. fal.ai Flux Pro (text-to-image)

**Endpoint:** `fal.run/fal-ai/flux-pro`
**Cost:** ~$0.05/image

**Result: BEST STYLE, but no likeness**

- Produces excellent caricature style — the user's preferred look
- Hyper-detailed skin, exaggerated proportions, dramatic lighting
- Black Mercedes suit with Petronas logos rendered well
- Warm amber backgrounds
- **Problem:** Text-to-image cannot generate a specific real person's face. Results look like generic "young F1 driver" not George Russell specifically.
- Generated 6+ variations (george_russell_flux_1.png, flux_2, flux_v2, flux_a through flux_d)
- **Key files (user's favourites):**
  - `test-output/george_russell_flux_1.png` — best overall style
  - `test-output/george_russell_flux_2.png` — similar quality
  - `test-output/george_flux_v2.png` — refined prompt, same style
- **Verdict:** Perfect style, zero likeness. Needs face identity injection.

### 3. fal.ai Flux Dev (image-to-image)

**Endpoint:** `fal.run/fal-ai/flux/dev/image-to-image`
**Cost:** ~$0.04/image
**Parameters:** `strength` (0.0-1.0), `num_inference_steps`, `image_size`

**Result: Works for caricature→caricature only**

- **Caricature input → caricature output (strength 0.55):** Excellent. Fed existing good Fernando Alonso caricature through i2i, got a refined version with same style, likeness preserved. (`test-output/fernando_from_caricature.png`)
- **Real photo input → caricature (strength 0.55):** Failed. Source photo barely transformed, green background bled through. (`test-output/fernando_from_real_photo.png`)
- **Real photo input → caricature (strength 0.70, 0.85):** Failed. Higher strength lost likeness entirely, backgrounds still wrong. (`test-output/fernando_real_s070.png`, `fernando_real_s085.png`)
- **Verdict:** Only useful if you already have a good caricature to refine. Cannot create caricatures from photos.

### 4. fal.ai Flux Kontext Pro (image editing)

**Endpoint:** `fal.run/fal-ai/flux-pro/kontext`
**Cost:** $0.04/image

**Result: Either too cartoony or too realistic — no middle ground**

Tested 5 prompt variations:

| Version | Prompt Strategy | Result |
|---------|----------------|--------|
| v1 | "satirical caricature portrait" | Oversized head, correct proportions, BUT googly cartoon eyes |
| v2 | "realistic satirical caricature, subtle" | Too realistic — basically a portrait photo, no caricature |
| v3 | "high-end collectible figurine" | Same as v2 — too realistic |
| v4 | "bobblehead, NO enlarged eyes" | Still googly eyes — ignores negative eye instructions |
| v5 | No caricature keywords, just "edit: make head larger" | Beautiful portrait, zero caricature effect |
| eye-fix | Fed v1 result back with "make eyes smaller and realistic" | Eyes fixed but caricature effect also reduced |

- **Key insight:** Kontext associates "caricature/bobblehead/satirical" with cartoon googly eyes. Without those words, it produces realistic portraits. There is no prompt that produces "photorealistic skin + oversized head + normal eyes."
- **Verdict:** Cannot hit the desired style. Either cartoon or photo.

### 5. fal.ai PuLID (face identity preservation)

**Endpoint:** `fal.run/fal-ai/pulid`
**Cost:** ~$0.04/image
**Parameters:** `prompt`, `reference_images` (array of `{image_url: ...}`)

**Result: Preserves face identity but different style**

- Takes a real face photo as identity reference, generates in prompted style
- Face identity IS preserved — output looks like the real person
- BUT the output style is different from Flux Pro (more illustrative, less cinematic)
- Tends to add helmets when racing/F1 keywords are in prompt
- Without racing keywords: face identity good, but style doesn't match desired look
- **Key files:**
  - `test-output/george_pulid.png` — helmet added, good face (first test)
  - `test-output/george_pulid_v3.png` — no helmet, recognizable face, wrong outfit
  - `test-output/george_pulid_v4.png` — teal suit, wrong style
- **Verdict:** Solves likeness but doesn't produce the Flux Pro style.

### 6. fal.ai IP-Adapter Face ID

**Endpoint:** `fal.run/fal-ai/ip-adapter-face-id`
**Cost:** ~$0.04/image
**Parameters:** `prompt`, `face_image_url`

**Result: Low quality, wrong colours**

- Only outputs 512x512
- Wrong suit colors (orange instead of black)
- Weaker likeness than PuLID
- **Verdict:** Not viable.

### 7. Style 3 options (editorial, painting, figurine)

Tested three distinct styles via Kontext Pro from George Russell photo:

| Style | File | Result |
|-------|------|--------|
| Editorial cartoon | `test-output/style1_editorial.png` | Clean flat cartoon, orange bg. Recognizable but very simple. |
| Digital painting | `test-output/style2_painting.png` | Barely transformed from photo. Green bg bleed. Not viable. |
| 3D figurine | `test-output/style3_figurine.png` | Smooth plastic render, correct proportions. Clean but generic. |

User rejected all three in favour of the Flux Pro style.

## Style Decision

**The Flux Pro text-to-image caricature style is the chosen style.** Reference images:
- `test-output/george_russell_flux_1.png`
- `test-output/george_russell_flux_2.png`
- `test-output/george_flux_v2.png`

Characteristics:
- Hyper-detailed skin with visible pores, stubble, fine wrinkles
- Slightly oversized/elongated head with exaggerated facial proportions
- Realistic expressive eyes (NOT cartoon)
- Dramatic warm side lighting with deep shadows
- Warm burnt-orange to dark amber gradient background
- Team-coloured race suit with sponsor logos
- Cinematic movie poster quality
- Portrait orientation (768x1344)

---

## Unsolved Problem

**Likeness.** The chosen style (Flux Pro text-to-image) cannot generate recognizable real people from text descriptions alone. All attempts produce "generic F1 driver" not the specific person.

### Approaches NOT yet tested

1. **Flux Pro text-to-image + face-swap tool** — Generate style image, then swap real face onto it
2. **SDXL + caricature LoRA on RunPod** — Fine-tune on caricature style, potentially train per-person LoRAs
3. **Flux Kontext with Flux Pro output as input** — Generate style, then tell Kontext to adjust face to match real person (tested once as `george_cinematic_v2.png` — style reverted to realistic)
4. **Multiple reference images in PuLID** — May improve likeness with more face angles
5. **Midjourney with --cref** — Character reference feature, not tested
